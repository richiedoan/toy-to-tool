# Limitations

- The catalogue and validator provide a consistent audit protocol; they do not prove that evidence is authentic or sufficient.
- Six criteria per group are a scoped project model, not comprehensive WCAG, ASVS, privacy, performance, resilience or operational certification.
- Essential, Standard and Advanced are project audit scopes and must not be mapped to ASVS certification levels.
- Browser, assistive-technology, production, load, recovery and credential-dependent conclusions require the corresponding real environment. Missing access remains `unknown`.
- Local timing is not field Core Web Vitals. Handler-level HTTP simulation is not proof of socket, proxy, browser, concurrency or deployed behavior.
- Fixture results show that workflows can be exercised against known defects. They do not establish improvement in arbitrary coding-agent performance.
- The installed-skill smoke used Codex CLI on macOS. Other agents and platforms are unverified.
- A `skills` CLI copied install can become stale relative to the source repository; reinstall deliberately after reviewing release changes.
- The controlled comparison has not run because the current profile is contaminated by ambient skills and lacks a reviewed environment receipt. No efficacy or cost comparison is available.
- Monetary cost is recorded only from an actual per-run billing receipt. Token usage and elapsed time are retained separately and are not converted using guessed prices.
